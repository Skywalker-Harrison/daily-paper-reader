## 摘要
如今，语音转文本引擎在不同应用中极为需要，是人机交互的一项重要使能技术。然而，一些语言仍面临标注语音数据匮乏的问题，尤其是在阿拉伯方言或任何低资源语言中。采用自监督训练过程以及利用噪声训练进行自训练，已被证明是新兴的可行解决方案之一。本文提出了一种面向低资源语言的端到端、基于 Transformer 的模型及框架。此外，该框架结合定制的音频到文本处理算法，以实现高效的约旦阿拉伯方言语音转文本系统。所提出的框架能够从多种来源摄取数据，并通过加速人工标注过程，使来自外部来源的真值成为可能。该框架允许使用噪声学生训练和自监督学习进行训练过程，从而在预训练和后训练阶段利用未标注数据，并融入多种类型的数据增强。所提出的自训练方法在词错误率降低方面比微调后的 Wav2Vec 模型高出 5%。这项工作的成果为研究社区提供了一个约旦口语数据集，以及一种处理低资源语言的端到端方法。这是通过利用预训练、后训练的能力，并以最少的人工干预注入带噪标注数据和增强数据来实现的。它为阿拉伯语语音转文本领域的新应用开发提供了可能，例如问答系统和智能控制系统，并将为智能机器人增加类人感知和听觉传感器。

## Abstract
Speech-to-text engines are extremely needed nowadays for different applications, representing an essential enabler in human-robot interaction. Still, some languages suffer from the lack of labeled speech data, especially in the Arabic dialects or any low-resource languages. The need for a self-supervised training process and self-training using noisy training is proven to be one of the up-and-coming feasible solutions. This article proposes an end-to-end, transformers-based model with a framework for low-resource languages. In addition, the framework incorporates customized audio-to-text processing algorithms to achieve a highly efficient Jordanian Arabic dialect speech-to-text system. The proposed framework enables ingesting data from many sources, making the ground truth from external sources possible by speeding up the manual annotation process. The framework allows the training process using noisy student training and self-supervised learning to utilize the unlabeled data in both pre- and post-training stages and incorporate multiple types of data augmentation. The proposed self-training approach outperforms the fine-tuned Wav2Vec model by 5% in terms of word error rate reduction. The outcome of this work provides the research community with a Jordanian-spoken data set along with an end-to-end approach to deal with low-resource languages. This is done by utilizing the power of the pretraining, post-training, and injecting noisy labeled and augmented data with minimal human intervention. It enables the development of new applications in the field of Arabic language speech-to-text area like the question-answering systems and intelligent control systems, and it will add human-like perception and hearing sensors to intelligent robots.

## 二、方法论：核心思想与关键技术细节

### 2.1 核心思想
- 采用**端到端（E2E）Transformer 架构**（基于 Wav2Vec 2.0），将特征工程、声学建模、语言建模统一到单一深度模型中。
- 融合**自监督学习（SSL）**与**自训练（噪声学生训练，Noisy Student Training）**，在预训练与后训练两个阶段充分利用未标注数据。
- 引入**定制化音频到文本处理算法**与**多源数据接入机制**，加速人工标注并提升数据多样性。

### 2.2 关键技术细节
- **Wav2Vec 2.0 两阶段结构**：
  - **自监督阶段**：利用未标注数据构建有意义的嵌入表示。
  - **潜在表示层**：由多层时序卷积单元组成，输入原始音频，输出潜在表示，经归一化与 GELU 激活。
  - **量化层**：通过 Gumbel Softmax 将潜在表示离散化为有限码字（音素），公式为：
    $$p_{g,v} = \frac{\exp(\text{sim}(l_{g,v} + n_v)/\tau)}{\sum \exp((l_{g,v} + n_v)/\tau)}$$
    其中 sim 为余弦相似度，$n$ 为 Gumbel 噪声，$\tau$ 为温度参数。
  - **上下文特征表示**：将量化输出送入深层 Transformer，建模序列上下文。
  - **微调阶段**：在上下文网络之上添加随机初始化的线性投影层作为分类层，冻结特征提取器，适配 ASR 任务。

- **自训练（噪声学生训练）流程**：
  1. 用全部标注数据训练初始**教师模型**；
  2. 教师模型对未标注数据推理，生成**伪标签**；
  3. 将伪标签数据 + 干净标注数据 + 增强数据组成更大规模的**学生模型**训练集；
  4. 在固定验证集上评估学生模型，迭代多代。

- **数据增强**：每代训练注入三类增强数据——高斯噪声（提升泛化）、时间拉伸、音高偏移（提升环境鲁棒性与对齐容错）。

- **数据预处理**：使用 VAD 按静音切分音频；统一降采样至 16 kHz；过滤时长 >20 s 或 <1 s 的记录；文本侧去除特殊字符、阿拉伯语变音符号、标点与重复字符，并归一化同音字符。

## 三、实验设计

### 3.1 数据集与场景
- **自建约旦方言数据集**：从 YouTube、Metaverse、网络红人、街头采访、新闻及政治讨论等多渠道采集。
- **数据规模**：共 97,000 条记录，总时长 113 小时；其中 52 小时通过 Google Cloud Speech + 人工转写标注（约 37,000 条已标注）。
- **语料特征**：约 35,000 个词项（未做词干化/词形还原，未去停用词），主题涵盖政治、旅游、宗教等。
- **音频特征**：平均时长 4.74 s（实验中采样后约 6 s），采样率 16 kHz。
- **标注流程**：先用 Google Speech API 生成初始转写，再通过 Doccano 协作标注工具进行人工修正与审核。

### 3.2 Benchmark 与对比方法
- **基准模型**：微调后的 Wav2Vec 2.0（教师模型，仅用标注数据训练）。
- **对比对象**：教师模型 vs. 第 1～5 代学生模型（混合标注、未标注与增强数据训练）。
- **评估指标**：词错误率（WER）与字符错误率（CER），WER 公式为：
  $$\text{WER} = \frac{S + D + I}{N}$$
  其中 S、D、I 分别为替换、删除、插入数，N 为参考词数。

### 3.3 实验设置
- 数据划分：80% 训练，20% 验证，验证集全程不参与训练。
- 初始标注训练数据：12.5 小时；未标注数据分 5 批，每批 2.5 小时。
- 跨语言无监督预训练基模型覆盖 53 种语言，在音素错误率上达到 SOTA。
