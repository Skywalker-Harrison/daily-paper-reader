## 摘要
大型音频语言模型（LALMs）能够遵循多样化的指令，以指定风格合成语音。然而，要求同时控制音高动态、语速和情感语调的复杂指令，往往超出单次生成所能忠实实现的范围。尽管近期的推理模型已表明，中间“思考”标记能提升输出质量，但这一范式一直局限于文本模态。在本工作中，我们通过强化学习训练一个 LALM 对其自身语音输出进行推理，从而将推理扩展到音频标记空间。该模型首先生成一段草稿语音，作为音频标记推理的一种形式；随后通过以文本反思声学实现来评判自身生成；最后在同时以第一遍语音和评判为条件的设定下生成精炼版本，且全部在单一模型内完成。经过强化学习训练后，精炼后的两跳输出在 InstructTTSEval 基准上取得了 7.15\% 的相对提升，展示了该模型的反思能力。

## Abstract
Large Audio Language Models (LALMs) can follow diverse instructions to synthesize speech in specified styles. However, complex instructions that require simultaneous control over pitch dynamics, speaking rate, and emotional tone often exceed what a single-pass generation can faithfully realize. While recent reasoning models have shown that intermediate "thinking" tokens improve output quality, this paradigm has been confined to the text modality. In this work, we extend reasoning to the audio token space by training a LALM with reinforcement learning to reason over its own speech output. The model first generates a draft speech as a form of audio-token reasoning, critiques its own generation by reflecting on the acoustic realization in text, and then produces a refined version conditioned on both the first-pass speech and the critique, all within a single model. After RL training, the refined two-hop outputs achieve a relative improvement of 7.15\% on the InstructTTSEval benchmark, demonstrating the model's reflective ability.

  - 已有的 RL-based Instruct TTS 工作（如 FlexiVoice、self-consistency reward 等）虽用 RL 后训练，但**未利用模型自身的推理能力**。
- **整体含义**：本文首次将推理范式从文本模态扩展到**音频 token 空间**，让同一个 LALM 在"生成—批判—精炼"（generate-critique-refine）的统一循环中跨文本与音频两种模态进行推理，为指令遵循语音合成提供新范式。

## 2. 方法论

### 2.1 核心思想

将语音合成建模为音频 token 空间的**两跳（two-hop）过程**：模型先生成草稿语音作为"音频推理"，再"聆听"自己的输出并用文本写出批判，最后基于草稿与批判重新生成精炼版本。三个阶段由**同一个模型**完成。

### 2.2 形式化流程

- **Pass 1（草稿生成）**：`v1 ~ pθ(· | s, t)`，其中 `s` 为风格指令，`t` 为文本内容。
- **Critique（自我批判）**：`c ~ pθ(· | s, t, v1)`，模型以音频 token 形式"听"自己的草稿，用自然语言指出声学实现与指令之间的具体不匹配。
- **Pass 2（精炼）**：`v2 ~ pθ(· | s, t, v1, c)`，基于草稿与批判生成精炼语音。
- 模型采用统一词表处理交错的文本与音频 token（选择 Step-Audio-2-mini，而非 thinker-talker 分离架构，因为后者不擅长在单一自回归序列中联合生成文本与音频）。
- **音频反 token 化细节**：使用参考说话人池缓解参考语音条件带来的性别不匹配——若指令含性别关键词（如 male、her），选择对应性别参考；否则选择 CLSP 分数最高的参考。参考池仅设 2 个说话人（Step-Audio-2 默认男/女声），以聚焦音频 token 推理本身。

### 2.3 RL 训练（GRPO）

- 对每个训练 prompt 采样 `G` 个 rollout `{v2^(i)}`，每个 rollout 条件于指令 `s`、文本 `t`、**预计算**的首跳 `v1`（训练效率考虑）以及批判 `c`。
- 组内相对优势：`A_i = (r_i − μ_G) / (σ_G + ε)`，其中 `μ_G`、`σ_G` 为组内奖励均值与标准差。
- 由于每批 rollout 只用于一次梯度更新，采样策略与被优化策略一致，**无需重要性采样比或 PPO 式裁剪**。
- 损失函数：策略梯度项（按组与序列长度归一化）+ 对冻结参考模型 `p_ref` 的 per-token KL 正则（系数 `β`）。
- 实现上对策略模型加 **LoRA**，基座冻结作为参考分布；通过禁用 LoRA adapter 即可高效获得参考 log-prob，从而计算 KL 项。

### 2.4 奖励设计

奖励同时评估**风格遵循**与**内容准确性**：

```
r = λ_style · CLSP(v2, s)
  + λ_imp · tanh(α · Δ)
  − λ_WER · max(0, WER(v2, t) − WER(v1, t))
```

- **风格遵循**：采用 CLSP（Contrastive Language-Speech Pretraining）计算生成语音与风格指令的余弦相似度，类比文本-图像领域的 CLIP score。
- **内容准确性**：用 ASR 转写 `v2` 并与参考文本 `t` 计算 WER。
- **精炼奖励（关键设计）**：加入改进量 `Δ = CLSP(v2, s) − CLSP(v1, s)`，鼓励"比草稿更好"而非仅最大化绝对质量。但**线性 Δ 在 GRPO 下会失效**——同一组内所有 rollout 共享同一个 `v1`，`CLSP(v1, s)` 是常数，在减去组均值时被抵消，优势退化为绝对 CLSP 的比较。因此将 Δ 通过 **tanh 非线性**（`tanh(α·Δ)`）：`tanh(α(a_i − c)) − mean_j tanh(α(a_j − c)) ≠ tanh(α a_i) − mean_j tanh(α a_j)`（对常数 c），从而在组相对优势中保留改进信号。
- **WER 惩罚项**采用相对形式（`v2` 相对 `v1` 的退化量），防止精炼牺牲可懂度。
- 超参数：`λ_style = 0.5`，`λ_imp = 1.0`，`α = 10.0`，`λ_WER = 0.5`。

## 6. 主要发现与结论

### 6.1 核心结论

- **两跳精炼显著优于单跳**：在 CLSP 与 LALM-as-a-judge 两套协议下，RL two-hop 均优于 RL one-hop 与 zero-shot，说明"自我批判 + 重生成"带来的增益**不能仅归因于 RL 微调本身**，而确实来自音频 token 空间中的推理循环。
- **RL 训练与精炼机制各自贡献可分离**：RL one-hop 相比 zero-shot 已有提升（说明 RL 能对齐 CLSP 风格奖励），而 two-hop 在 one-hop 基础上进一步提升，证明批判环节提供了额外的、可被利用的"诊断信号"。
- **跨任务泛化**：提升不仅在域内 DSD 上出现，也在格式差异较大的 APS 与 RP 上成立，说明模型学到的是通用的"听—评—改"能力，而非针对某一指令模板的过拟合。

### 6.2 奖励设计的发现

- **tanh(α·Δ) 是必要设计**：由于同一 GRPO 组内共享同一 `v1`，线性 Δ 在组相对优势中被常数抵消，退化为绝对 CLSP 优化；实验（Table IV）证实非线性变换能恢复"改进量"信号，效果优于线性 Δ 与无说话人检索的原始设置。
- **WER 相对惩罚有效**：以 `v1` 为基准的相对 WER 惩罚，在提升风格遵循的同时抑制了可懂度退化。

### 6.3 批判内容与模型能力的发现

- **批判必须"自我产生"**：Table VII 显示 `self` 批判优于 `fixed`（固定/模板化批判）与 `none`，说明批判的有效性依赖于它与**当前草稿的具体声学缺陷**之间的对应关系，模板化批判无法提供针对性诊断。
- **批判能力可被 RL 增强**：RL adapter 产生的批判比 base（pre-RL）模型更有效，暗示 RL 不仅提升了生成，也提升了"听觉批判"本身的质量。

### 6.4 说话人检索的作用

- 参考说话人池（按指令性别关键词或 CLSP 最高分选择）能缓解参考条件导致的性别不匹配，在 zero-shot 模型上即带来 CLSP 提升（Table V），是保证评测公平与风格可控的重要工程细节。

- **实验强度**：主实验 + 奖励消融 + 说话人消融 + 批判消融 + 人工评测 + 案例研究，覆盖面较全，且设计了 one-hop 对照来隔离机制贡献，公平性设计优于多数同类工作。
- **可提升空间**：跨模型、跨数据集、更大规模训练、统计显著性、与同期 RL 方法的直接对比，是后续工作应补齐的关键环节。
- **意义**：该工作为"音频生成中的推理"提供了首个较系统的范式示例，若后续能在更多基座与更大数据上复现其增益，有望推动 Instruct TTS 从"单次映射"走向"迭代自我改进"。
