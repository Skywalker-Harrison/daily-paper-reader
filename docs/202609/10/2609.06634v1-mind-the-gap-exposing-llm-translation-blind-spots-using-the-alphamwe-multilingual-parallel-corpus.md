## 摘要
LLM 在机器翻译（MT）任务上的表现通常取决于其训练时特定领域和语言对的数据可用性。为了考察多词表达（MWE）是否仍在语言理解和翻译方面对 LLM 构成瓶颈，我们报告了 WMT2026 测试套件共享任务的系统性能，其中我们使用公开可用的多语言平行语料库 AlphaMWE 作为测试套件。我们收到了 31 个 MT 系统的输出，涵盖英语到汉语（zh）、波兰语（pl）、德语（de）、阿拉伯语（ar），其中包括现代标准阿拉伯语（MSA）以及两种方言阿拉伯语（埃及阿拉伯语和突尼斯阿拉伯语）。我们使用 BLEU、ChrF、BERT-score 进行自动评估，以选出每个语言对的前 3 个系统，随后对所选系统进行了人工评估。我们的发现表明：比喻性/MWE 现象仍然具有挑战性；自动指标有时并不一致；人工评估揭示了被总体分数掩盖的语言特定错误。

## Abstract
LLMs' performance on machine translation (MT) tasks is often dependent on the data availability in the specific domains and language pairs that they are trained upon. To examine if Multiword Expressions (MWEs) still set a bottleneck for LLMs regarding language understanding and translation, we report the system performances from the WMT2026 Test Suites shared task, for which we used the publicly available multilingual parallel corpus AlphaMWE as the test suites. We received 31 MT systems' outputs covering English to Chinese (zh), Polish (pl), German (de), Arabic (ar) including Modern Standard Arabic (MSA) and two dialectal ones (Egyptian and Tunisian Arabic). We carried out automatic evaluations using BLEU, ChrF, BERT-score to select the Top3 systems per language pair, followed up with human evaluations on the selected systems. Our findings show that: figurative/MWE phenomena remain challenging; automatic metrics sometimes disagree; human evaluation uncovers language-specific errors hidden by aggregate scores.

# 论文总结：《Mind the Gap: Exposing LLM Translation Blind Spots Using the AlphaMWE Multilingual Parallel Corpus》

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 在机器翻译（MT）上已取得很高的流畅度和自动评分，但整体质量高并不意味着所有语言现象都被同等处理。
- **核心问题**：多词表达（MWEs）、习语、隐喻/比喻性语言等**非组合性构式**，其意义无法从单个词直接推断，因此仍是 LLM 理解与翻译的潜在瓶颈。
- **已有研究缺口**：
  - 先前工作（Cheng & Amiri 2025；Laureano De Leon et al. 2025；Mi et al. 2025；Liu et al. 2026；Liang & Han 2026）多聚焦单一语言现象，或局限于受控实验设置。
  - 对**多样化的当代 MT 系统在共享多语言诊断基准上的整体表现**了解不足。
  - BLEU、BERTScore 等自动指标只给出总体质量估计，容易掩盖涉及习语性、词义歧义、比喻意义的错误。
- **研究意义**：通过 WMT 2026 Test Suites 共享任务，把 AlphaMWE 作为诊断型测试套件，系统检验 MWE 与比喻语言是否仍是当代 MT 系统的"盲点"。

## 2. 方法论：核心思想与技术流程

- **总体思想**：三阶段流水线——测试套件构建 → 自动评估 → 人工评估与分析（论文图 1）。
- **Stage I：测试套件构建**
  - 基于 AlphaMWE 多语言平行语料（含 MWE 标注、机器翻译后编辑、人在回路质量控制）。
  - 数据来源包括 PARSEME 共享任务，最初覆盖英–德、英–波、英–中，后扩展至阿拉伯语版本。
  - 文本体裁混合：IT 文档说明、新闻/政治、文学作品。
  - 原始语料 5 个文件、每文件约 150 段、共 747 段；英–阿、英–波标注不完整，故英–MSA/英–AEB/英–ARZ 各 150 段，英–波 597 段。
  - 处理步骤：合并子集（aa–ae）、语言特定参考译文、转换为 WMT 要求的 JSONL 格式。
- **Stage II：自动评估**
  - 使用三个互补指标：
    - **SacreBLEU**：精确导向的 n-gram 匹配；
    - **chrF++**：稳健的字符级匹配；
    - **BERTScore F1**：上下文语义相似度。
  - **系统排序方法**：不采用平均分数，而采用**平均排名（average rank）**，因为三个指标数值尺度不同。
  - 具体做法：先用每个指标对每个语向的系统单独排名，再对三个指标的排名取平均；采用竞赛排名（competition ranking）确定最终名次。
  - 额外报告 **Rank SD（排名标准差）**，用于衡量三指标的一致性：
    - SD = 0 表示三指标排名完全一致；
    - SD 较小（0.4–1.0）表示较强一致；
    - SD > 2 表示指标分歧显著，系统质量评价依赖所选指标。
  - Rank SD **不作为选择标准**，仅用于解释排名。
- **Stage III：人工评估**
  - 采用 **HOPE**（以人工后编辑为中心的任务导向评估框架）。
  - **8 类错误**：Impact（IMP）、Required Adaptation Missing（RAM）、Terminology（TRM）、Ungrammatical（UGR）、Mistranslation（MIS）、Style（STL）、Proofreading（PRF）、Proper Name（PRN）。
  - **严重度等级**：0、1、2、4、8、16，分别对应轻微、中等、重大、严重、极严重。
  - 由母语者对每个语向 Top3 系统进行标注，汇总错误惩罚分（SEGS）并做定量与定性分析。

## 6. 主要结论与发现

- **MWE 与比喻语言仍是盲点**：即使自动评分很高，习语、动词性 MWE、隐喻/比喻表达、词义歧义、语言特定搭配仍是重要错误来源。
- **体裁差异显著**：文学与表达丰富的文本错误最多；技术与新闻类文本翻译明显更可靠（术语固定、上下文易推断）。
- **自动指标存在分歧**：约一半入选系统的 Rank SD = 0（三指标一致），另一半存在不同程度分歧；极端案例如 en→arz 上 GPT 5.5（SD=3.559）和 Gemma 4-31B（SD=1.886）。en→zh 的并列第 1 也由 SD 解释：SCIR-TG-MT SD=0.471 比 Google Translate SD=0.943 更一致。
- **人工评估揭示聚合分数掩盖的语种特有错误**：
  - **英–阿**：TRIVE 最佳（总分 57），Google Translate 中等（84），Gemma 4-4B 最差（284）。MIS 是最大错误类别；习语直译（如 "this broke everybody up"）导致语义不通；术语一致性、专名音译、calque、单位未换算等问题突出。语法错误反而较少，且部分"语法异常"实为语域/搭配问题。
  - **英–中**：SCIR-TG-MT（52）远优于 Google Translate（98）和 Tower 9B（167）。MIS、PRF、TRM 最突出。习语/比喻直译是主要问题（如 "lifting a little finger"、"took it back"）。文学文本难度高于 IT 文档。
  - **英–德**：TRIVE 风格更"文学化"，善用德语习语（"Zahn der Zeit"、"kein Auge trocken"），但有时牺牲精确性；工程语境中 "standard" 应译为 "Norm" 而非 "Standard"，涉及法律后果差异。
  - **英–波**：整体质量高但体裁差异大；STL 最多，其次 MIS。问题包括动词体（imperfective vs. perfective）、语法性别、单/复数与正式/非正式"you"、搭配自然度、领域术语（如 czyste pojazdy vs. pojazdy ekologiczne）。
- **句级评估的局限**：缺少文档上下文时，多个译文可能同样合法（如 "you" 的性别、体、敬称选择），基于参考译文的句级评估可能惩罚合法变体。
- **总体结论**：高自动指标不等于无重要语言错误；单一自动指标不足以完整刻画翻译质量；应结合互补自动指标与针对性人工评估。

## 7. 优点（方法或实验设计亮点）

- **诊断导向的资源设计**：AlphaMWE 自带 MWE 标注，是专门用于暴露非组合性语言现象的测试套件，而非通用评测集。
- **多语向、多方言覆盖**：同时覆盖中、德、波和阿拉伯语三变体（MSA、埃及、突尼斯），对低资源方言翻译有独特价值。
- **三指标互补 + 平均排名**：避免单一指标偏差，且用排名而非分数聚合，规避了 BLEU/chrF/BERTScore 量纲不可比的问题。
- **引入 Rank SD 作为一致性诊断量**：不仅给出排名，还量化自动指标之间的分歧程度，对解释并列排名尤其有用。
- **自动 + 人工双轨验证**：用 HOPE 的 8 类错误与 6 级严重度，提供比聚合分数更细粒度的诊断信息。
- **定性案例丰富**：正文与附录给出大量真实例句（英–阿、英–中、英–波），覆盖习语直译、词义误选、体、搭配、术语、作用域歧义等，具有较强解释力。
- **透明性与可复现性**：附录 D 给出全部系统的三指标分数与排名表，便于复核。
- **自我批判意识**：作者主动讨论句级评估惩罚合法变体、标注严重度主观性、跨语言比较的标注者偏差等问题。
