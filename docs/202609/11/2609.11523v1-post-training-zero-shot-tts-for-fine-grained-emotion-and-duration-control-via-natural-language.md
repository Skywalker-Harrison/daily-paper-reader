## 摘要
有声书旁白、对话智能体和视听配音都需要语音在单个话语内传达不断变化的情感并调整其节奏。然而，大多数现有TTS系统通常依赖话语级的风格条件控制，使得这种细粒度控制难以实现。鉴于此，并受大语言模型后训练成功的启发，我们提出了一种统一的后训练框架，使预训练的文本到语音模型具备通过自然语言对片段级情感和时长进行控制的能力。监督微调建立了指令条件化的语音生成，而采用组相对策略优化的强化学习则利用情感和时长奖励以及内容和说话人保持目标来优化控制精度。通过复用预训练架构，我们的方法避免了额外的推理时控制模块。实验表明，该方法在保持语音可懂度和说话人身份的同时显著提升了细粒度可控性，凸显了后训练作为扩展现有语音合成模型的一种实用途径。

## Abstract
Audiobook narration, conversational agents, and audiovisual dubbing require speech that conveys changing emotions and adapts its pacing within a single utterance. But most existing TTS systems typically rely on utterance-level style conditioning, making such fine-grained control difficult to achieve. In light of this, and inspired by the success of post-training in large language models, we propose a unified post-training framework that equips pretrained text-to-speech models with natural-language control over segment-level emotion and duration. Supervised fine-tuning establishes instruction-conditioned speech generation, while reinforcement learning with group relative policy optimization refines control accuracy using emotion and duration rewards alongside content and speaker preservation objectives. By reusing the pretrained architecture, our approach avoids additional inference-time control modules. Experiments demonstrate significantly improved fine-grained controllability while maintaining speech intelligibility and speaker identity, highlighting post-training as a practical approach to extending existing speech synthesis models.

# 论文总结：基于自然语言实现细粒度情感与时长控制的后训练零样本 TTS

## 1. 核心问题与整体含义（研究动机与背景）

- **应用需求**：有声书旁白、对话智能体、视听配音等场景要求**单个话语内部**出现情感变化与节奏/时长的局部调整（例如同一句中不同片段对应不同视觉事件或时间约束）。
- **现有瓶颈**：主流大规模 TTS 虽支持情感、风格、时长控制，但控制信号通常在**话语级（utterance-level）**施加，无法满足一句内多片段的差异化需求。
- **已有细粒度方案的局限**：
  - PromptTTS、InstructTTS 等自然语言指令系统只描述整句。
  - WeSCon（片段级情感提示 + 语速调整）、TED-TTS（片段条件 + 推理时引导）、MAGIC-TTS（token 级时长与停顿控制）虽能局部控制，但依赖**结构化控制信号或专门推理流程**，不够直观灵活。
- **核心思路**：受大语言模型"后训练（post-training）"范式启发，用**自然语言指令**表达每个片段的情感/时长要求，并通过分阶段后训练直接改造预训练 TTS 模型，从而**不引入任何推理时控制模块**。

## 2. 方法论

### 2.1 总体框架
- 以 **CosyVoice2 的语音语言模型**为骨干进行训练；**语音 tokenizer、声学生成器、vocoder 全部冻结**。
- 输入：文本切分为 K 个 span（x₁…x_K）+ 自然语言指令 c（指定各 span 的情感、时长或相对语速）；目标：一次生成满足全部局部要求、同时保持内容与参考说话人身份的完整语音。
- 流水线：**情感 SFT → 情感 GRPO → 时长 SFT → 时长 GRPO → 联合 GRPO → 指令等价蒸馏 → 短程混合 GRPO**。

### 2.2 训练数据构建
- **情感数据**：取 MED-TTS 的 5 类情感，用 **IndexTTS2** 合成标注片段；说话人参考来自 Seed-TTS，情感参考来自 ESD（人工筛选 + MERaLiON-SER-v1 分类置信度，每类保留 top-3）。分片段合成后拼接并人工筛查。
- **时长与联合数据**：基于 LibriTTS-R 转写录音，对同说话人片段用**保音高的 PSOLA** 独立拉伸/压缩后拼接；由实测时长生成"精确时长"指令，由施加的时长比例生成"相对语速"指令。同一文本的不同变换提供不同时间要求样本（时长监督仅用英文构建，但观察到可泛化到中文评测集）。将该流程同样施加于情感语音即可获得"情感+时长"联合监督。

### 2.3 各训练阶段关键技术
- **情感 SFT**：在构造音频提取的目标语音 token 上做自回归交叉熵 `L_CE`（指令作为条件上下文，不进入朗读目标）。
- **情感 GRPO**：每条指令采样多个候选并解码；用 **Qwen3-ForcedAligner** 对齐得到各受控片段的音频区间，用 **MERaLiON-SER-v1** 预测情感。奖励 = 情感置信度 + 片段级准确率 + 严格话语级准确率（所有片段都对才算对），并叠加 ASR 内容一致性与说话人相似度奖励；即 `R = R_ctrl + λ_asr·R_asr + λ_spk·R_spk`，GRPO 在组内偏好高奖励候选并对偏离参考策略做正则。
- **时长 SFT**：在情感精调模型上做时长数据微调，并加入**情感回放（emotion replay）**缓解遗忘。损失 `L_dur-SFT = L_CE + λ_len·L_len + λ_bnd·L_bnd`，两个辅助项用 smooth-L1 监督 log token 数与累计归一化边界，**训练专用头在推理前移除**。
- **时长 GRPO**：对齐后测量片段时长；精确时长请求用平滑得分 `s_k = exp(−|log(d̂_k/d_k)|/τ_d)`；相对语速请求按区间符合度与目标比例接近度打分。时长奖励 = 软得分 + 片段级 + 严格话语级 + 累计边界一致性。**反事实时长变体**（同文本、同说话人、不同时长要求）各自构成独立 GRPO 采样组，组内比较而非跨指令排序。
- **联合精调**：混合情感单控、时长单控、联合控制样本；内容与说话人奖励对所有任务生效，情感/时长奖励按任务类型加权聚合，以恢复并保持情感控制、巩固时间合规性。
- **指令等价蒸馏（IED）**：规范指令 c 配多个同义改写 c̃（控制意图相同）。冻结的联合 GRPO 检查点作教师，在 c 下生成高质量语音 token 目标；蒸馏时教师条件为 c、学生条件为 c̃，共享文本与 token 历史，损失 `L_IED = L_CE(z*|x, c̃) + λ_KL·Σ D_KL(p̄_T^t ‖ p̄_θ^t)`，即叠加 token 级 KL 分布匹配。蒸馏后再做一短程混合任务 GRPO 恢复控制精度。

## 7. 方法评价与局限

- **设计亮点**：
  - 把 LLM 后训练范式（SFT → GRPO → 蒸馏 → 短程 RL）系统性迁移到片段级可控 TTS，控制信号全程为自然语言，推理阶段**零额外模块**，部署简洁。
  - 奖励设计区分"片段级"与"严格话语级"，并用对齐器把连续音频切回受控区间，使 RL 能对局部片段直接施奖，思路清晰。
  - 用**反事实构造**（同文本、同说话人、不同控制要求）作为独立采样组，避免跨指令排序带来的混淆，是 RL 数据组织上较严谨的一点。
  - 训练数据全部由现有语料变换合成（教师 TTS + PSOLA 时长变换），不依赖新采集，成本相对可控。
- **潜在局限**：
  - **联合控制严格成功率偏低（5.29%）**，距离"一句话内多片段同时满足情感+精确时长"的实际可用仍有差距。
  - 情感类别仅 5 类、时长控制以拉伸/压缩合成音频为监督，**真实韵律多样性与细粒度强度控制**未被充分覆盖；PSOLA 变换可能引入非自然韵律，模型或学到"合成伪影"而非真实时长变化规律。
  - 依赖多个外部模型（IndexTTS2 合成、MERaLiON-SER-v1 打分、Qwen3-ForcedAligner 对齐、SenseVoice ASR、emotion2vec+ 验证），**评测与训练存在对第三方模型能力的耦合**，任一组件偏差会传导至结论。
  - **超参数与消融披露不足**：λ_asr/λ_spk/λ_len/λ_bnd、KL 权重、温度 τ_d、蒸馏改写数量等均未见系统消融，难以判断各损失项贡献。
  - 时长监督主要在英文构建，中文评测的泛化虽被观察但未做定量拆解；英/中 1:2 的混合评测也未按语言分别报告。
  - 对比基线中 TED-TTS、MAGIC-TTS 以"oracle 结构化输入"参与，与本文自然语言接口**并非同一输入范式**，其对比公平性有限（作者已声明，但结论解读仍需谨慎）。

## 8. 启示与可迁移点

- **范式层面**：将"控制能力内化进生成模型、推理零控制器"的思路，可迁移到语速、停顿、重音、风格、情感强度等更多语音属性的细粒度控制。

  - "SFT 打底 → RL 提精度 → 蒸馏提鲁棒 → 短程 RL 回收精度"是一条可复用的多阶段后训练配方。
  - 用强制对齐把音频切回控制区间，从而支持**局部奖励**，是处理片段级/时序类控制任务的通用技巧。

- **评测层面**：双分类器交叉验证 + 分类器分歧样本人工听测 + 拼接自然度 MOS，是一套值得借鉴的"防奖励过拟合"评测组合。
