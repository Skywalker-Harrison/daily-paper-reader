## 摘要
零样本文本到语音（TTS）可以从短音频提示中克隆说话人的声音，但大多数 TTS 系统在推理时仍需要音频提示的转录文本。当音频提示的转录文本不可用时，这种依赖会阻碍跨语言语音克隆，尤其是对于未见语言。Cross-Lingual F5-TTS 消除了这一依赖，实现了无需转录文本的跨语言语音克隆，但它使用强制对齐来准备训练数据。强制对齐对边界错误敏感，且随着覆盖语言数量增加，其成本也随之增长。当音频提示以静音开头或结尾时，其语速预测器在估计时长方面也不可靠。本文提出 Cross-Lingual F5-TTS 2，一个无需强制对齐、无需转录文本的跨语言语音克隆简化框架。我们不使用强制对齐来分割真实话语，而是利用预训练的 F5-TTS 模型构建同一说话人的提示与目标对，并在这些构造出的数据对上微调同一模型。这简化了数据准备，并保留了预训练模型的声学建模能力，使得仅需短暂微调阶段即可完成适配。我们进一步通过静音感知增强，使音节级语速预测器对首尾静音具有鲁棒性。实验表明，Cross-Lingual F5-TTS 2 在保持可懂度的同时，相比 F5-TTS 和 Cross-Lingual F5-TTS 达到更高的说话人相似度。所有相关资源均已公开可用。

## Abstract
Zero-shot text-to-speech (TTS) can clone a speaker's voice from a short audio prompt, yet most TTS systems still require the audio prompt transcript during inference. This dependency prevents cross-lingual voice cloning when the audio prompt transcript is unavailable, particularly for unseen languages. Cross-Lingual F5-TTS removes this dependency and enables transcript-free cross-lingual voice cloning, but it prepares its training data with forced alignment. Forced alignment is sensitive to boundary errors, and its cost grows as more languages are covered. Its speaking rate predictor is also unreliable at estimating duration when the audio prompt begins or ends with silence. In this paper, we present Cross-Lingual F5-TTS 2, a simplified framework for transcript-free cross-lingual voice cloning without forced alignment. Instead of using forced alignment to segment real utterances, we build same-speaker prompt and target pairs using a pretrained F5-TTS model and fine-tune the same model on these constructed pairs. This simplifies data preparation and preserves the acoustic modeling capability of the pretrained model, enabling adaptation with only a short fine-tuning stage. We further make the syllable-level speaking rate predictor robust to leading and trailing silence through silence-aware augmentation. Experiments show that Cross-Lingual F5-TTS 2 reaches higher speaker similarity than F5-TTS and Cross-Lingual F5-TTS while maintaining intelligibility. All related resources are publicly available.

# Cross-Lingual F5-TTS 2 论文总结

## 1. 核心问题与研究背景

- **问题起点**：零样本 TTS（语音克隆）可从短音频提示中复制说话人音色，但绝大多数系统在推理时仍**要求提供音频提示的转录文本**（transcript）。
- **跨语言场景的痛点**：当参考说话人与目标文本属于不同语言时，提示文本往往不可靠甚至无法获得（尤其低资源/未见语言的自发语音），转录依赖直接阻断跨语言克隆。
- **现有两条免转录路线的缺陷**：
  - **全局说话人嵌入路线**（YourTTS、Qwen3-TTS 的嵌入模式）：绕过转录，但只保留粗粒度身份，丢失 in-context 提示所携带的局部音色与韵律。
  - **同说话人提示-目标对路线**（MOSS-TTS、IndexTTS 系列）：保留 in-context 保真度，但依赖说话人日志/单说话人切分等**重型数据预处理流水线**。
- **F5-TTS 的特殊困难**：F5-TTS 中提示转录承担**双重角色**——既构成文本侧条件，又通过"提示文本与目标文本的长度比"决定目标时长。去掉转录会同时破坏文本条件与时长估计。
- **前作 Cross-Lingual F5-TTS 的残留问题**：
  - 用 **MMS 强制对齐**切分真实话语（VoXtream2 亦如此），对边界错误敏感，语言覆盖越广成本越高（VoXtream2 因对齐失败/无效转录丢弃约 35% 语料）。
  - 其**音节级语速预测器（SRP）**在提示音频首/尾含静音时失效：静音拉低估计语速 → 预测时长被高估 → 合成语音被拉伸，损害自然度与可懂度。
- **论文含义**：提出 Cross-Lingual F5-TTS 2，在**无需强制对齐、无需提示转录**的前提下实现语言无关的跨语言音色克隆，简化数据准备并仅需短微调即可适配。

## 2. 方法论

### 2.1 核心思想
- 保留 F5-TTS 的**语音填充（speech infilling）+ 流匹配**范式，用**预训练 F5-TTS 自合成的同说话人提示**替代强制对齐切分出的真实提示，从而构造"真实-合成"配对做监督微调（SFT）。
- 用**可学习提示 token + EOS 标记**填补被删掉的提示转录位置，保持预训练阶段的"文本-音频"布局对齐。

### 2.2 关键技术细节
- **真实-合成配对构造**：对每条真实训练样本，以该样本自身为音频提示、从对应语言的文本池抽取目标文本，用预训练 F5-TTS 合成同说话人的新话语作为 `x_syn_prompt`；原始真实语音作为目标 `x_target`。无需外部强制对齐器。
- **SFT 输入构造**：
  - 声学输入按时间轴拼接：`x1 = [x_syn_prompt ; x_target]`。
  - 设提示与目标帧长分别为 τ₁、τ₂，总长 τ = τ₁ + τ₂，定义二值时间掩码 `m[:, j] = 0 (j ∈ [0, τ₁))`，`m[:, j] = 1 (j ∈ [τ₁, τ))`。即 `(1−m)⊙x1` 暴露合成提示作为声学条件，`m⊙x1` 掩蔽真实目标作为预测区域。
- **提示 token 文本条件（Prompt-Token Text Conditioning）**：
  - 文本序列 `z = [⟨P⟩ × N, ' . ', c₁…c_M, ⟨F⟩ × (τ−N−M−2)]`，其中 `c₁…c_M` 为目标文本 token，`⟨F⟩` 为填充 token。
  - **N 个可学习提示 token ⟨P⟩**：作为无转录提示的显式指示符，并在文本序列中为声学提示提供占位；N 由**提示与目标语音时长的比例**决定，使该区域长度近似于提示转录在预训练文本条件中本应占据的长度。
  - **EOS 标记 " . "**：复用 F5-TTS 预训练中已学到的句/话语结束线索，标出提示 token 区与目标文本的边界，加速收敛。
- **静音鲁棒语速预测器（Silence-Robust SRP）**：
  - 沿用前作的音节级 SRP（Transformer，输入 mel 频谱，输出离散语速类别），训练用**高斯交叉熵（GCE）**损失：
    - `L_GCE = −(1/Ns) Σᵢ Σ_c y_c^soft log(ŷ_c)`，软标签 `y_c^soft = exp(−(c − c_gt)² / (2σ²))`，σ = 1.0 控制软标签平滑度。
  - **静音感知增强**：训练时以一定概率在提示音频前/后/两侧插入静音；**架构与标签不变**，仅增强预测器的声学输入（标签仍由未加静音的真实语音决定）。
  - 具体概率设置：70% 不变，前/后/双侧各 10%；插入静音时长在原始提示时长的 **30%–70%** 间均匀采样。
- **推理**：沿用 F5-TTS 设置，Euler ODE 求解器、NFE = 32、CFG 强度 2.0、sway 采样系数 −1.0、Vocos 声码器；目标时长由音节级 SRP 从提示音频与目标文本估计，而非文本长度比。

  - **数据规模子集**（按 DNSMOS 最高、双语言平衡筛选）：真实/合成小时数分别为 1,000/286、2,000/574、5,000/1,443、95,282/29,169。
- **评测集 / Benchmark**：
  - **语内**：LibriSpeech-PC test-clean、Seed-TTS test-en、Seed-TTS test-zh。
  - **跨语言**：8 种训练分布外（OOD）提示语言——韩语（Emilia）、越南语（Dolly-Audio）、泰语/印尼语/法语/德语/俄语/马耳他语（Common Voice），每种语言配 500 条英语 + 500 条中文目标句，共 **16 个跨语言子集**（提示语言始终不同于目标语言）。
  - **静音鲁棒性**：在原始干净提示与"双侧各加 50% 提示时长静音"的 padded 提示下对比。
- **对比基线**：F5-TTS（比例法时长估计）、Cross-Lingual F5-TTS（原未加静音增强的 SRP）。
- **指标**：
  - 客观：WER（Whisper-large-V3 测英文、Paraformer-zh 测中文）、SIM-o（WavLM-large 说话人验证嵌入余弦相似度）、UTMOS（自然度客观代理）。

## 6. 主要结论与发现

- **语内表现**：Cross-Lingual F5-TTS 2 在三个测试集上均取得**最高 SIM-o**（0.687 / 0.683 / 0.768），WER 与两基线相当（LibriSpeech-PC test-clean 最低，2.014%），说明用合成提示替换真实提示**不损害可懂度**。
- **相似度提升的机理**：合成提示提供更"干净"的条件信号——真实录音带有不稳定韵律与副语言信息，模型须先"折扣"这些信息才能复制音色；合成提示更平稳朴素，使模型更可靠地学到说话人身份。
- **自然度代价**：UTMOS 与 CMOS 略低于两基线，SMOS 高于 Cross-Lingual F5-TTS 但低于 F5-TTS。原因是合成提示韵律较平坦（SIM-o 主要反映音色，SMOS 同时反映音色与韵律）。作者认为这是为换取显著相似度提升的**可接受折衷**。
- **跨语言泛化**：16 个语言对中 **14 个** SIM-o 更高，UTMOS 略低，WER 相当；模型可在**无提示转录

转录、无需强制对齐的条件下，仍能稳定迁移音色；跨语言相似度提升主要来自合成提示对说话人身份的"纯化"，而非对目标语言音素或韵律的建模增益。

### 6.5 静音鲁棒性（Silence-Robust SRP）

- **时长预测**：在"双侧各加 50% 提示时长静音"的 padded 提示下，原始 SRP 的语速估计被静音拉低，导致预测时长系统性偏长，MRE/MAE 明显恶化；静音增强 SRP 在 padded 条件下将 MRE/MAE 拉回接近干净提示的水平，且**在干净提示下也未出现退化**，说明静音感知增强是"无损"的鲁棒性补丁而非权衡。
- **下游 TTS**：时长误差的减小直接传导到合成质量——padded 提示下，静音增强 SRP 的 WER 更低、SIM-o 更高、UTMOS 更优，与干净提示的差距显著收窄。由于本方法**仅改变时长估计、不改变声学条件与文本条件**，该实验构成对"时长预测误差→合成自然度/可懂度"因果链的受控验证。
- **意义**：真实场景中的参考音频常带首尾静音、呼吸停顿或录音留白，该增强使系统摆脱对"提示必须被精确裁剪"的隐含要求，与"免强制对齐"的整体设计目标一致。

### 6.6 文本条件消融

- **占位符必要性**：A0（直接删除提示转录位置、不留占位）最差，说明预训练 F5-TTS 已强绑定"文本序列长度 ↔ 音频帧数"的布局先验，突兀缺失会破坏该对齐；A1（纯填充 token）优于 A0，但缺乏对"此处为提示区"的显式语义指示。
- **提示 token 的作用**：A2（可学习 ⟨P⟩）相对 A1 有进一步提升，表明可学习提示 token 能在文本侧为声学提示提供更可辨识的"锚点"，让模型区分"提示区"与"目标文本区"。
- **EOS 标记的作用**：A3（⟨P⟩ + EOS " . "）最优，且收敛曲线显示其达到同等 WER 所需 SFT 步数更少，验证了复用预训练中已学到的句边界线索可加速适配、稳定边界定位。
- **比例设计**：N（⟨P⟩ 数量）由提示与目标语音时长比例决定，使提示 token 区在文本序列中占据与"真实转录本应占长度"近似的位置，是 A2/A3 生效的前提；若 N 与声学提示时长严重失配，占位优势会被削弱。

### 6.7 微调数据规模消融

- 性能随真实/合成数据规模（1K→2K→5K→95K 小时）单调改善，但**边际收益递减**：1K–5K 小时区间已可获得接近全量数据的 WER 与 SIM-o，说明该方法**数据效率较高**，短微调即可适配。
- 该结论与"仅需短微调即可适配"的设计主张一致：预训练 F5-TTS 提供的强先验 + 合成提示构造的"真实-合成"监督，使模型无需海量配对数据即可学会"以合成提示为条件复制音色"。
- 需注意：不同规模间的 WER/UTMOS 差异量级较小（0.005–0.05），部分差异可能落在评测噪声内，规模效应的稳健性有待更大规模或多次重复实验确认。

## 7. 贡献与定位

- **方法层面**：首次在 F5-TTS 框架内同时解除**提示转录依赖**与**强制对齐依赖**，用"预训练模型自合成同说话人提示 + 真实目标"构造配对监督，并以**可学习提示 token + EOS** 复原文本-音频布局；配套提出**静音鲁棒 SRP**，修补前作在提示含静音时的时长估计失效。
- **数据层面**：将数据准备从"说话人日志/单说话人切分/强制对齐 + 转录"的重型流水线，简化为"任取真实话语 → 自合成提示"的轻量流程，避免了对齐失败导致的语料丢弃（对比 VoXtream2 约 35% 丢弃率）。
- **实证层面**：在 3 个语内测试集与 8 种 OOD 提示语言、16 个跨语言语言对上验证了音色相似度的稳定提升与可懂度的保持，并通过消融隔离了各设计变量的贡献。

## 8. 局限与未来方向

- **自然度折衷**：UTMOS/CMOS 略低于基线，SMOS 低于原生 F5-TTS，根源在于合成提示韵律较平坦；未来可探索"更富韵律的合成提示构造"或在 SFT 中引入韵律正则/偏好优化，以在保持音色优势的同时回收自然度。
- **评测覆盖**：主观评测每测试集仅 15 条且无置信区间/显著性检验；跨语言目标语言仅英语与中文；未与说话人嵌入路线（YourTTS、Qwen3-TTS）和同说话人配对路线（MOSS-TTS、IndexTTS）直接对比，跨路线优劣尚不明确。
- **算力报告**：给出了 GPU 型号、数量与更新步数，但未报告墙钟时间/总 GPU 小时，也未披露 29,169 小时合成语音的生成成本，复现与成本评估受限。
- **依赖预训练模型**：合成提示质量受预训练 F5-TTS 能力上界约束，若基座在目标说话人/语言上本身表现不佳，配对监督的信号质量会下降；对极低资源语言的适用性仍取决于基座覆盖。
- **可能的延伸**：将该"自合成提示 + 占位 token"范式推广到其他 in-context TTS 架构；探索无需 SRP、由模型端到端预测时长的方案；在更广语言与更严苛录音条件下（噪声、混响、多人重叠）验证鲁棒性。

## 9. 总体评价

Cross-Lingual F5-TTS 2 是一篇**工程取向明确、问题拆解清晰**的工作：它没有追求架构创新，而是精准定位 F5-TTS 中"提示转录的双重角色"这一结构性障碍，用"自合成提示替代真实提示 + 可学习占位 token"给出低成本解法，并以静音增强补齐前作的时长估计短板。其实验链条完整（语内主实验、跨语言泛化、文本条件消融、数据规模消融、静音鲁棒性），结论内部自洽——**以轻微自然度代价换取显著且跨语言稳定的音色相似度提升与数据准备简化**。主要短板在于主观评测规模小、缺少与异路线方法的横向对比、以及算力成本披露不完整；但就"免转录、免对齐的跨语言零样本 TTS"这一目标而言，该方法在简化流程与保持可懂度方面具有明确的实用价值。
