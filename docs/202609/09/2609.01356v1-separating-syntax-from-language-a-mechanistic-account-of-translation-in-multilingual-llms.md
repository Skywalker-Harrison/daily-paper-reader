## 摘要
多语言大语言模型（mLLMs）在机器翻译中取得了强劲的性能，但我们对它们如何将表示从一种语言转换为另一种语言的机制的理解仍不完整。先前的研究表明，翻译可分解为mLLM内多个可分离的过程，其中概念内容首先被独立表示，随后生成特定语言形式。在这项工作中，我们表明翻译比先前假设的更加模块化，并且翻译过程中的输出语言生成实际上可进一步区分为句法过程和表层语言过程。我们构建了受控的多语言数据集，以分离跨语言的词序差异，并使用因果干预和探针分析来追踪翻译过程中表示的转换。我们发现，模型在实现目标语言表层形式之前，首先构建目标侧的词序。我们识别出一些个体注意力头，它们对句法变换具有选择性敏感性，而对语言身份基本保持不变。这些结果证实了形成句法结构是翻译中的一个独立阶段，扩展了先前的分解，并展示了翻译如何由mLLMs内功能不同的组件实现。

## Abstract
Multilingual large language models (mLLMs) achieve strong performance in machine translation, yet our understanding of the mechanisms by which they transform representations from one language to another remains incomplete. Prior work suggests that translation decomposes into separable processes within an mLLM, where conceptual content is first represented independently, followed by a production into language-specific form. In this work, we show that translation is even more modular than previously assumed and that the output language production in translation processes is actually further separable into a syntax and a surface language process. We construct controlled multilingual datasets that isolate cross-linguistic differences in word-order and use causal interventions and probing to track how representations are transformed during translation. We find that models first construct target-side word-order before realizing the target language surface form. We identify individual attention heads that are selectively sensitive to syntactic transformations while remaining largely invariant to language identity. These results establish the commitment to a syntactic structure as an independent stage in translation, extending prior decompositions and showing how translation is implemented by functionally different components within mLLMs.

## 1. 论文的核心问题与整体含义

- **研究动机**：多语言大语言模型（mLLMs）虽然具备较强的机器翻译能力，但其内部“如何将一种语言的表征转换为另一种语言”的机制仍不清晰。已有研究（如 Dumas et al., 2025）提出翻译可分解为**概念内容（conceptual content）** 与**输出语言（output language）** 两个可分离过程，即模型先形成与具体语言无关的语义表征，再生成目标语言形式。但该框架并未考察**语言生成内部是否可进一步分解**——尤其是句法结构（如词序）与表层语言形式是否由不同阶段、不同部件实现。
- **核心问题**：当源语言与目标语言在词序系统上存在差异（如形容词-名词顺序、主谓宾与主宾谓语序、情态动词位置等）时，模型对目标侧语法结构（特别是词序）的“承诺”（commitment）是否构成一个独立且先于表层语言实现的翻译阶段？该阶段是否由特定网络组件（如注意力头）完成，且这些组件是否与语言身份无关？
- **整体含义**：作者提出一种**更细粒度的三段式翻译分解**：句法结构 S（syntax，主要指词序）先于表层语言 L（surface language）被确定，表层语言 L 再先于词汇内容/概念 C（lexical content/concept）被确定，即 **S → L → C** 的递进式处理策略。这不同于以往将翻译看作“通过英语中间表征直接映射”或“通过抽象中间语单步转换”的观点，说明 mLLMs 的翻译是一个多阶段、模块化的计算过程，语法结构在其中被早期、相对独立地构建。

## 2. 方法论

- **核心思想**：通过构造**句法差异受控的平行语料**，将翻译过程中的三类信息（S、L、C）分离，然后利用**激活修补（activation patching）** 与 **LogitLens** 等方法追踪和干预中间层表征，观察它们随网络深度的变化，从而判断三类信息分别在哪些阶段被“固定”，并定位负责句法转换的内部组件。
- **技术细节**：
  - **三种被追踪的信息维度**：
    - S（syntactic structure）：目标句的**词序**（如形容词-名词 vs. 名词-形容词，动词-宾语 vs. 宾语-动词，情态动词-不定式 vs. 不定式-情态动词）；
    - L（surface language）：目标句的**表层语言**（如法语、荷兰语等）；
    - C（lexical content）：目标句的**词汇概念**（如“绿车” vs. “红椅”）。

  - **提示格式**：
    ```
    [Source language]: [Source sentence] - [Target language]: [Incomplete target]
    ```
    采用 one-shot 格式（提示中附加一条来自同一数据集的完整翻译示例），使待生成的下一个 token 恰好落在目标句的某个关键句法位置（如名词短语中间），从而便于检测词序选择。

  - **实验模式**：构建 base prompt（基线）和 plant prompt（干扰源）。两者在 S、L、C 三个维度上系统性地不同：例如 base 是英语→法语（名词-形容词顺序，绿色汽车），plant 是英语→荷兰语（形容词-名词顺序，红色椅子）。然后对模型的某一层（或某个注意力头）做**激活替换**：运行 base 输入但替换其中部分激活为 plant 输入产生的激活，观测下一步 token 概率在 2³=8 种 (S,L,C) 组合间的移动。
  - **评估指标**：不同 token 类型（如“保持 base 还是切换为 plant”的三维组合）在修补前后的概率差最大值 Δmax 及其对应层；还使用 **KL 散度**比较均值激活修补下基线与修补后分布差异。

  - **注意力头分析**：对“S 切换层”内每个注意力头分别修补，用比值指标
    \[
    R(h, t) = \frac{P(t \mid \text{Patch}(h))}{\frac{1}{|H|}\sum_{h_i \in H}P(t \mid \text{Patch}(h_i))}
    \]
    衡量单个注意力头对目标 token 的“超常”影响，从而识别句法敏感头（S-heads）。

  - **语言无关性检测**：对 S-head 的激活执行**均值激活修补**——用来自另一目标语言样本的平均激活替换原激活。对比两种情况：修补语言与 base 目标语言具有相同的词序（期望不影响输出），以及词序不同（期望改变输出的词性选择但不改变语言）——从而验证该注意力头编码的是独立的句法特征而非语言特征。

## 3. 实验设计

- **模型**：选择三个规模与训练数据分布差异显著的多语言模型：
  - **mGPT 1.3B**：训练语料平衡、无主导语言；
  - **Aya Expanse 8B**：预训练语言分布未公开；
  - **Llama 3 8B**：以英语为主。  
  目的：考察翻译机制是否通用，还是受预训练英文主导度影响。

- **数据集（自建受控语料）**：
  - **NP（名词短语）**：197 个样本，覆盖 8 种语言（英语、法语、意大利语、越南语为名词-形容词序：N-Adj；荷兰语、德语、俄语、中文为形容词-名词序：Adj-N），考察**形容词与名词的顺序**；
  - **SVO（主谓宾）**：154 个样本，5 种语言（英语、俄语、中文为 SVO；日语、土耳其语为 SOV），考察**子句层面词序**；
  - **MV（情态动词）**：31 个样本，4 种语言（英语、德语、中文 vs. 土耳其语），考察**情态动词与不定式的相对顺序**。
  - 所有表达式由英语源句翻译至各目标语言，并用 DeepL 翻译后人工校对词序，剔除/修正偏离典型词序的案例。
  - 另外附录中用 **FLORES-200** 抽取 27 句自然数据（NP Natural）做了初步补充验证。

- **语言对配置**：共考虑 90 组三元组（源语言、base 目标语言、plant 目标语言）用于 NP 数据集；SVO 为 36 组，MV 为 16 组。所有组合均要求 base 与 plant 目标语言词序不同。
- **实验变体**：
  1. LogitLens 分析中间层 token 概率演化；
  2. 整层激活修补（定位 S、L、C 各自切换的关键层）；
  3. S 层内单注意力头修补（识别 S-head）；
  4. 对 S-head 进行跨语言均值激活修补（检验语言无关性）；

## 6. 主要结论与发现

1. **翻译存在 S → L → C 的递进阶段**：对 mGPT、Aya Expanse 与 Llama 3 的大多数数据集组合，激活修补显示最早受影响的是句法（词序），随后是表层语言，最后才是词汇内容。例外：Llama 3 在 SVO 数据集中，句法与表层语言在同层（14 层）切换，表现为 S,L → C 的压缩策略。
2. **句法承诺先于表层语言实现**：LogitLens 观测到中间层预测往往先出现符合目标词序的“英语 token”（例如法语目标为名词-形容词时先预测英语名词），说明模型在底层先确定了目标语序，但输出 token 尚停留在英语中间表征。也就是说，英语中介表征更多是“概念锚定物”而非“句法中介”。
3. **句法承诺部分定位于个别注意力头**：在 Llama 3 和 Aya Expanse 中，S 切换层分别存在单一注意力头（H14.25、H15.0）强烈控制词序；mGPT 则将效果分布在多个头上（H11.2、H11.7 等），而且 mGPT 的语法头同时影响表层语言，使得句法与语言不易分离。
4. **S-head 是功能性的“语言无关句法头”**：在 Llama 3 和 Aya Expanse 中，对 S-head 进行跨语言均值激活修补时，替换为“词序相同”的语言几乎不改变预测，替换为“词序不同”的语言则改变词性预测而不提高修补语言本身的概率。因此这些头编码词序但不编码语言身份。
5. **S-head 的表征几何不按词序聚类**：余弦相似度分析显示，同一 S-head 在不同语言的平均激活不因词序相同而更相似，说明这种句法编码是“功能性”而非几何结构上的显式聚类。
6. **英语的中介作用需要重新解释**：中间表征虽然偏向英语 token，但其反映的已是目标语言词序；因此，英语并不是句法转换的枢轴语言，而更像一种“中立概念表征”的语言输出出口。

## 7. 优点

- **研究角度新颖且切分细致**：首次将词序（句法结构）作为区别于表层语言和概念内容的第三个可追踪维度，比先前“概念/语言”两分解更进一步，丰富了对 mLLM 翻译机制的认知。
- **以因果干预为主**：大量使用激活修补而不是只依赖相关性分析，能够较直接地确定注意力头、层与不同翻译过程之间的因果关系。
- **数据构造精巧**：为排除混淆变量精心构造最小对照句对（base-plant 仅在 S/L/C 上可控变化），对跨语言词序配对做了严格控制，并用多语种覆盖不同语系和词序类型。
- **跨模型选择有策略性**：选择预训练语料分布差异明显的三款模型（英语偏置程度不同），使结论能讨论“是否依赖英文主导训练”等变量。
- **结论有层次感**：不单报告“哪个层做什么”，还通过均值激活修补与余弦相似度分析了 S-head 的功能性质（语言无关但非几何显性），推断“英语作为概念锚而非句法中介”，解释力较强。

## 8. 不足与局限

- **结构覆盖有限**：只研究名词短语词序、子句主谓宾/主宾谓语序、情态动词位置三种现象，未涉及格标记、长距离依赖、复杂从句等。不同句法现象可能对应不同神经机制，无法简单外推。
- **因果干预的固有假设**：激活修补假设相关计算是可“替换”和近似线性的，但实际网络计算可能是非线性、非模块交互的，因此结论需要谨慎解读。
- **模型代表性不足**：mGPT（1.3B）是非英语偏置数据的唯一代表，但规模过小，无法完全代表更大规模均衡多语模型；Aya Expanse 的训练分布未公开，也无法确认其是否真的无英语偏置；作者选的三模型均属于 8B 及以下级别，未覆盖更大模型。
- **数据为合成语料，规模小**：数据集为最小句对，数量少、句式简单，可能无法反映真实文本的复杂性和分布；FLORES-200 验证仅 27 句，统计效力弱。提示词采用 one-shot 且来自同数据集，可能触发模型利用格式捷径，未必反映无示例翻译的内部策略。
- **实验配置不完整**：NP 数据集中没有覆盖所有 base 目标语言方向（因计算限制）；SVO/MV 数据集很小（MV 仅 31 条）。这些可能造成抽样偏差。
- **部分结果不一致**：mGPT 中语法头与语言头重叠、Aya 在均值修补中的词序效应不对称、以及当德语作为 base 目标时效果缺失等异常未能深入解释；作者将部分现象归因于英语的“中性”地位，但并未系统验证。
- **未给出计算资源报告**：无法评估实验成本或可复现性；代码链接仅简略提及，没有提供完整可复现的完整环境描述。
