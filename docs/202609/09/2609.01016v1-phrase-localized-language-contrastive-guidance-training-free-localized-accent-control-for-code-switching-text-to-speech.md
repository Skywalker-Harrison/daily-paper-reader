## 摘要
当前的语音合成在处理码切换时会遇到困难，码切换指的是在外语短语中混入主要语言的话语，导致该短语以主要语言的口音而非其母语口音说出。我们提出了短语级语言对比引导（LCG），这是一种无需训练的推理框架，可在跨语言文本到语音合成中恢复码切换短语的母语口音。LCG 将应用于整个话语的单一语言引导替换为对每个区域分别进行引导，从而使每个部分都由其自身的语言引导。为了选择应用这种局部引导的位置，我们提出了一种自注意力探测技术，无需外部对齐即可找到短语边界。这些组件共同生成的语音中，每个区域都带有其自身语言的口音，无需微调或辅助模型。在不同语言对之间，LCG 显著提高了码切换短语的母语度，同时抑制了口音泄漏，并保持了整体说话人身份和自然度。

## Abstract
Current speech synthesis struggles with code-switching, which mixes a foreign language phrase into a primary language utterance, causing the phrase to be spoken with the primary language's accent rather than its native one. We propose Phrase-Localized Language-Contrastive Guidance (LCG), a training-free inference framework that restores a native accent to code-switched phrases in cross-lingual text-to-speech. LCG replaces the single language guidance applied across the whole utterance with a separate guidance for each region, so each part is guided by its own language. To choose where to apply this localized guidance, we propose a self-attention probing technique that finds the phrase boundaries without external alignments. Together, these components generate speech in which each region carries the accent of its own language, requiring no fine-tuning or auxiliary models. Across diverse language pairs, LCG robustly increases the nativeness of the code-switched phrase while suppressing accent leakage, and preserving overall speaker identity and naturalness.

## 1. 核心问题与整体含义

### 研究动机与背景
- 零样本多语言/跨语言文本到语音合成（TTS）模型已能实现高质量跨语言音色克隆，但当说话人提示语音的语言与目标文本语言不一致时，会产生严重的**跨语言口音泄漏**，即用主语言（matrix language）的口音来读外语内容。
- 在**语码切换（Code-Switching, CS）**场景中，问题尤为突出：一句话里混入外语句子片段（embedded phrase），模型往往将该片段发音“压平”成主语言口音，破坏听感。
- 现有主流方法依赖**Classifier-Free Guidance (CFG)** 提升文本遵守和音质，但 CFG 对整段语音统一施加引导，无法对不同区段做差异化控制，反而加剧了口音泄漏。
- 已有的一些大规模多语言模型（如 OmniVoice，支持 600+ 语言）仍然存在这种问题；即便 X-Voice 等双语言注入架构，也需大规模微调且仍难优化句内语码切换。
- 现有解决方案多需微调、引入额外模型，或在全局层面对时间步做调度，缺少**不依赖训练、不引入外部对齐模型**的局部口音控制方案。

### 整体含义
论文提出一种**无训练、推理时执行的“短语级语言对比引导（Phrase-Localized Language-Contrastive Guidance, LCG）”**框架，能够在码切换语音合成中，只对嵌入的外语短语区域施加其母语语言引导，从而恢复母语口音，同时保持主语言载体的说话人身份与自然度。核心思想是“每个区域由其自身语言引导”，而非全局统一引导。

## 2. 方法论

### 总体框架
LCG 构建在离散扩散语言模型（DLM）之上（如 OmniVoice），整个流程分为三个阶段：
1. **自注意力探测（Self-Attention Probing）** —— 从模型内部注意力中动态提取短语级音频帧掩码；
2. **掩码细化（Mask Refinement）** —— 通过“双标签联合”与“边缘膨胀”最大程度扩大短语边界召回率；
3. **短语级语言对比引导** —— 将独立语言对比引导向量（scale=λ）叠加到局部掩码区域，实现局部口音控制。

### 关键技术细节

#### (a) 短语定位：自注意力探测
- 对每个生成的音频帧，观察解码器层中该帧对文本 token 的自注意力，取注意力权值最大的 token 索引。
- 若该 token 落在文本中嵌入短语的字符范围内，则将该音频帧标记为 1，否则为 0。
- 经验确定最优层为 **L8 与 L12**，并采用多个注意力头取最大值的方式进行融合。
- 该设计源于一个“非对称容错”观察：**漏报（false negative）会导致短语口音崩溃、是灾难性的；而误报（false positive）会被主语言的文本上下文自然纠正，因而危害较小**，因此定位策略优先保证召回率。

#### (b) 掩码细化
- **双标签掩码联合（Dual-Tag Mask Union）**：对主语言条件化得到掩码 \(m_{src}\)，对短语语言条件化得到掩码 \(m_{phr}\)，两者做逻辑或：  
  \(m_{XU} = m_{src} \lor m_{phr}\)
  - 因为切换语言标签会轻微移动注意力对齐边界，联合两个掩码可互相补全遗漏边界帧。
- **边缘膨胀（Margin Dilation）**：对联合掩码做对称梯度膨胀，膨胀半径呈三角累积 \(r_k = \sum_{s=1}^{k} s = k(k+1)/2\)；
  - 实验取 \(k=4\)，等价于约 ±10 帧窗口。
  - 过度膨胀造成的误报区域会被离散扩散模型的迭代去噪过程自然吸收，不会破坏矩阵载体质量。

#### (c) 语言对比引导的代数推导
标准 CFG 为：
\[
\tilde{l} = c_{src} + \gamma (c_{src} - u)
\]
其中 \(c_{src}\) 为主语言条件 logit，\(u\) 为无条件 logit，γ 为全局引导权重。

首先提出一个直觉基线 Swap，将短语条件 logit \(c_{phr}\) 只应用于掩码区域：
\[
\tilde{l}_{swap} = \tilde{c} + \gamma(\tilde{c} - u), \quad \tilde{c} = (1-m)c_{src} + m c_{phr}
\]
展开后得到：
\[
\tilde{l}_{swap} = [c_{src} + \gamma(c_{src} - u)] + m(1+\gamma)(c_{phr} - c_{src})
\]
可见 Swap 等价于“全局主语言 CFG + 局部注入对比向量 \(c_{phr}-c_{src}\)”，但注入强度被隐式地“绑定”为 \(1+\gamma\)，无法独立控制。

LCG 则将其替换为独立参数 \(\lambda\)：
\[
\tilde{l}_{LCG} = [c_{src} + \gamma(c_{src} - u)] + m\,\lambda\,(c_{phr} - c_{src})
\]
由此实现“**语言控制强度 λ 与全局文本引导 γ 的解耦**”，λ 可在无需重新训练的情况下自由调节（实验中 λ=3 即等价 Swap，λ=7 为最优）。

## 6. 主要结论与发现

1. **LCG 显著提升嵌入短语的外语母语度**：
   - 12 方向总体 MER 从 0.564 降至 0.445；
   - 嵌入短语语言准确率 LA_e 从 0.233 提升至 0.518（翻倍以上）；
   - 语言识别置信度 LID_e 从 0.247 提升至 0.588。

2. **几乎不损害全局自然度与说话人一致性**：
   - UTMOS 从 3.411 小幅降至 3.285；
   - SIM 仅从 0.973 降至 0.969，SIM_{m↔e} 从 0.961 降至 0.959。

3. **掩码来源的“矛盾”结论**：比离线强制对齐 oracle 更好，说明在码切换场景中“高召回、动态掩码”比“高精度、静态掩码”更有效（因为扩散过程可自然吸收少量误报，但漏报会导致口音塌陷）。

4. **λ 的解耦至关重要**：
   - λ=3（等效 Swap）外口音提升非常有限；
   - 外口音指标随 λ 呈对数饱和，最佳折中点为 λ=7；
   - λ=7 时人工听感（MOS 3.931 与基线 4.007 的重叠置信区间）无显著差异，而 AB 偏好测试中 75.5% 的听者认为 LCG 的嵌入短语更接近母语者发音。

5. **对真实人类语料同样有效**：在韩英真实对话转录上，Baseline < Swap < LCG 的顺序在两类嵌入长度（长短语和单词插入）上保持一致。

6. **大模型并不天然解决口音泄漏**：MOSS-TTS（8B）在相同评估下仍与未引导 OmniVoice 相近，说明全局语言条件化无论规模如何都无法解决短语级口音控制。

## 7. 优点与亮点

1. **完全无训练、无需辅助模型**：直接在预训练 DLM 的推理阶段做 logit 级引导，对既有系统侵入性小。
2. **动态自监督定位**：用内部自注意力探测代替外部强制对齐工具，自动获得短语边界，且保持“高召回优先”的策略与离散扩散模型的容错特性自然匹配。
3. **数学上清晰解耦**：从 Swap 的显式分解中识别出耦合限制，提出独立的 λ 参数，实现可控的口音强/弱调节。
4. **轻量实用**：只需额外一条语言条件前向路径（约 1.4× 计算），总推理速度仍远快于实时；如果只在 L8/L12 两层启用 eager 注意力，其余 26 层仍可用融合核，可进一步降低开销。
5. **构建并开源平衡基准语料**：1200 句、12 方向、多词密集插入，弥补了以往最多单词插入型基准的空白。
6. **评估严谨且多维度**：不仅有自动指标，还包含人工实验、真实语料验证、注意力加权鲁棒性检验、外部系统参考对比，以及推理成本分析。
7. **论文自我反思充分**：明确讨论局限与伦理风险，结论诚实。

## 8. 不足与局限

1. **实验覆盖有限**：
   - 语料仅 1200 句，文本为合成生成，可能与真实口语风格存在偏差；
   - 仅覆盖英/德/法/日/韩五种语言，缺少低资源或非字母/音节书写系统语言，跨语系泛化未验证；
   - 主观评估只面向英语嵌入方向（JA/KO→EN），未评估其他嵌入语言的人类感知。

2. **方法适配范围窄**：
   - 与离散扩散语言模型深度绑定；应用于自回归 TTS 时，局部对比插入可能累积误差，未被验证；
   - 需要已知嵌入短语的字符跨度；同脚本混合（如拉丁语系内部切换）时需额外语言标识或外部信息。

3. **评估中的潜在偏差**：
   - UTMOS 在码切换语音上明显偏差（视切换为 OOD），故文中采用人工 MOS 作补充；
   - 短语级 ASR/语言 ID 指标在单词语码切换段上不稳定，真实语料测试中甚至出现一条 ASR 循环重复异常；
   - 与 MOSS-TTS 的对比不是同骨干公平比较，只能代表规模化大模型也未必解决的参考证据。

4. **可调节性带来的风险**：
   - λ 巨大时可能产生过度夸张或刻板化的口音，论文将其列为伦理问题；
   - 无训练方法仍可能被用于多语种深度伪造。

5. **推理效率的提示成本**：
   - LCG 需要 eager 注意力而非 SDPA/FlashAttention，导致约 2.26× 总体时间开销；虽然仍快于实时，但受限于无法使用融合核，在更长音频或资源受限场景中可能成为瓶颈。
   - 文中没有与真实声学环境下的整体端到端延迟或不同 GPU 设置做更全面测量。

6. **关于真实世界语码切换**：
   - 真实对话中语码切换常为单词插入且带主语言口音色彩，此时“母语化渲染”不等于普适目标；λ=0 可回归基线，但方法的“最优”短语边界计算规则在有大量同音同形异义（同脚本）的现实中仍不够自动。
